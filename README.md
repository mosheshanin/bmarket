# BMarket — каталог бизнесов на продажу в Израиле

Telegram Mini App и сайт в одном приложении: посетители смотрят объявления и оставляют заявки, менеджеры мгновенно получают заявки в Telegram, два администратора ведут каталог прямо в мини-приложении.

ТЗ — [`docs/SPEC.md`](docs/SPEC.md) · запуск — [`docs/DEPLOY.md`](docs/DEPLOY.md) · отступления от ТЗ — [`docs/DECISIONS.md`](docs/DECISIONS.md)

## Что умеет
**Посетителю** (Telegram и браузер, одни и те же страницы)
- Главная с лентой городов (только города с объявлениями), закреплёнными и новыми лотами, меткой «Новое».
- Страница города, карточка лота: галерея со свайпом и полноэкранным просмотром, цена в ₪ и ≈ USD/EUR по курсу Банка Израиля, показатели 2×2, описание (Markdown), что входит в продажу, характеристики, видео, «Поделиться».
- Форма заявки: имя, телефон (05X-XXX-XXXX или +…), способ связи, комментарий, согласие; в Telegram — «Поделиться номером», системные кнопки, вибрация; в браузере — Turnstile.
- Подписка на новые бизнесы (в Telegram — `requestWriteAccess`, в браузере — ссылка в бота).

**Менеджерам**
- Заявка сохраняется в базе и уходит в группу с кнопками «Взять в работу» и «Открыть в админке»; 3 повтора при сбое, недоставленные — вверху списка.

**Администраторам** (вкладка «Админ-панель» внутри мини-приложения)
- Объявления: фильтр по статусам, просмотры и заявки за 30 дней, публикация/снятие/дублирование/удаление черновиков.
- Форма лота: 5 блоков, форматирование чисел, авторасчёт окупаемости, Markdown-редактор, до 15 фото со сжатием в браузере и перетаскиванием, автосохранение каждые 10 с, защита от одновременной правки, предпросмотр, журнал изменений.
- Заявки: фильтры, скрытые данные лота, звонок/WhatsApp/Telegram, статусы ↔ сообщение в группе, CSV.
- Справочники городов и отраслей, подписчики и история рассылок, статистика с графиком.

**Система**
- SEO: SSR, title/description/canonical, Open Graph, schema.org (Product+Offer, BreadcrumbList, Organization), `sitemap.xml`, `robots.txt`, 301 при смене названия, 410 для снятых лотов.
- Кеш публичных страниц 10 минут со сбросом при изменениях.
- Cron: рассылки порциями по 40/мин (не чаще раза в 2 часа, подборкой), курс Банка Израиля ежедневно, удаление ПДн заявок через 24 месяца, удаление фото через 30 дней.
- Резервная копия D1 раз в неделю (GitHub Actions → R2).

## Быстрый старт локально
```bash
npm ci
cp .dev.vars.example .dev.vars
npm run db:migrate:local && npm run db:seed:local && bash scripts/seed-photos.sh --local
npm run build && npx astro preview --port 8787 --host 127.0.0.1
# в другом терминале
npm test && npm run test:e2e
```
Откройте http://127.0.0.1:8787. Админ-панель работает только внутри Telegram (подпись initData).

## Стек
Astro 7 (SSR) · Cloudflare Workers Free · D1 + Drizzle · R2 · React · Tailwind 4 · grammY · Zod · Vitest.
Размер Worker ≈ 0,4 МБ gzip (лимит 3 МБ).

## Проверки
- `npm test` — 26 юнит-тестов: подпись initData (подделка, чужой токен, срок 24 ч), скрытые поля, форматы, санитайзер Markdown, разбор курсов.
- `npm run test:e2e` — 96 сквозных проверок на живом Worker: страницы, SEO, отсутствие скрытых данных в HTML, 401/403 админ-API, создание и публикация лота с фото, заявки и лимит 5/час, CSV, статистика, подписка, вебхук.
- `NODE_PATH=$(npm root -g) node tests/e2e/screens.mjs` — скриншоты ключевых экранов (320 px, телефон, десктоп, Telegram светлая/тёмная, админка) с проверкой горизонтальной прокрутки.
