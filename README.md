# BMarket — каталог бизнесов на продажу в Израиле

Telegram Mini App и сайт в одном приложении: посетители смотрят объявления и оставляют заявки, продавцы сами
размещают объявления, менеджеры мгновенно получают заявки в Telegram, администраторы ведут каталог прямо в мини-приложении.
Запуск — вместе с клубом предпринимателей HaifaBusinessClub.

- **Работает:** https://bmarket.moshemadwords.workers.dev · бот [@bismarketbot](https://t.me/bismarketbot)

## Что умеет

**Посетителю** (Telegram и браузер, одни и те же страницы)
- Заставка при открытии мини-приложения (≈21,5 с, «Пропустить», уход — раскрытие круглым вырезом).
- Главная с лентой городов (только города с объявлениями), карточки по 5 с кнопкой «Показать ещё»; страница города;
  карточка лота: галерея, цена в ₪ и ≈ USD/EUR по курсу Банка Израиля, оборот, прибыль, окупаемость, описание,
  что входит в продажу, бейджи «Оценка подтверждена» / «Пройден аудит», «Поделиться».
- Форма заявки (в Telegram — «Поделиться номером», системные кнопки; в браузере — Turnstile после подключения домена).
- Подписка на новые бизнесы; опрос при первом запуске и «Подборка для вас» (выключено, включается в админке).

**Продавцу** — «Мои объявления» (`/sell`, команда `/sell`, ссылка `t.me/bismarketbot?start=sell`): пошаговая форма
с автосохранением, платные услуги (оценка и аудит), заявка на размещение уходит менеджерам; промо-блок
«Ваше объявление заметят»; правки после публикации — через запрос администратору.

**Менеджерам** — заявки покупателей и заявки на размещение приходят в группу Telegram с кнопками
«Взять в работу» и «Открыть в админке»; 3 повтора при сбое.

**Администраторам** (кнопка «Админ-панель» на главной в мини-приложении) — объявления, форма лота с фото
(сжатие в браузере, перетаскивание, автосохранение, предпросмотр, журнал), объявления продавцов и оплата,
заявки + CSV, справочники (города включаются галочкой), подписчики и рассылки, статистика и опрос.

**Система** — SSR и SEO (schema.org, sitemap, 301/410), кеш 10 минут, рассылки подборками, курс валют раз в день,
удаление ПДн через 24 месяца, самонастройка бота после деплоя, бэкапы D1 через GitHub Actions.

## Стек
Astro 7 (SSR) · Cloudflare Workers Free · D1 + Drizzle · Workers KV (фото) · React · Tailwind 4 · Nunito · grammY · Zod · Vitest.
Размер Worker ≈ 0,42 МБ gzip (лимит 3 МБ).

## Локально
```bash
npm ci
cp .dev.vars.example .dev.vars
npm run db:migrate:local && npm run db:seed:local && bash scripts/seed-photos.sh --local
npm run build && npx astro preview --port 8787 --host 127.0.0.1
# в другом терминале
npm test && npm run test:e2e
```
Откройте http://127.0.0.1:8787. Админ-панель и «Мои объявления» работают только внутри Telegram (подпись initData);
сквозные тесты и `tests/e2e/screens.mjs` подставляют подписанный initData сами.

## Деплой
`git push origin main` — Cloudflare Workers Builds собирает и выкладывает автоматически (≈1 мин). Подробности — `docs/DEPLOY.md`.

## Проверки
- `npm test` — 37 юнит-тестов: подпись initData, скрытые поля, форматы, санитайзер Markdown, курсы валют, адреса фото,
  подбор под ответы опроса, понятные ошибки Telegram, PayPal.
- `npm run test:e2e` — 182 сквозных проверок на локальном Worker (с поддельным PayPal на :8799).
- `NODE_PATH=$(npm root -g) node tests/e2e/screens.mjs` — скриншоты ключевых экранов.
- CI (`.github/workflows/ci.yml`) прогоняет всё это на каждый push.
