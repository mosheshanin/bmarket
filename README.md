# BMarket — каталог бизнесов на продажу в Израиле

Telegram Mini App и сайт в одном приложении: посетители смотрят объявления и оставляют заявки, менеджеры мгновенно получают заявки в Telegram, администраторы ведут каталог прямо в мини-приложении.

- **Работает:** https://bmarket.moshemadwords.workers.dev · бот [@bismarketbot](https://t.me/bismarketbot)
- **Состояние и что дальше:** [`docs/STATUS.md`](docs/STATUS.md) ← начинать отсюда
- ТЗ: [`docs/SPEC.md`](docs/SPEC.md) · инфраструктура: [`docs/DEPLOY.md`](docs/DEPLOY.md) · отступления от ТЗ: [`docs/DECISIONS.md`](docs/DECISIONS.md) · правила для ИИ: [`CLAUDE.md`](CLAUDE.md)

## Что умеет
**Посетителю** (Telegram и браузер, одни и те же страницы)
- Заставка «Сторис» при открытии мини-приложения (≈6,7 с, можно пропустить).
- Главная с лентой городов, закреплёнными и новыми лотами; страница города; карточка лота: галерея, цена в ₪ и ≈ USD/EUR по курсу Банка Израиля, показатели, описание, что входит в продажу, характеристики, видео, «Поделиться».
- Форма заявки (в Telegram — «Поделиться номером», системные кнопки; в браузере — Turnstile после подключения домена).
- Подписка на новые бизнесы.

**Менеджерам** — заявка сохраняется и уходит в группу Telegram с кнопками «Взять в работу» и «Открыть в админке»; 3 повтора при сбое.

**Администраторам** (кнопка «Админ-панель» в мини-приложении) — объявления, форма лота с фото (сжатие в браузере, перетаскивание, автосохранение, предпросмотр, журнал), заявки + CSV, справочники, подписчики и рассылки, статистика.

**Система** — SSR и SEO (schema.org, sitemap, 301/410), кеш 10 минут, рассылки порциями, курс валют раз в день, удаление ПДн через 24 месяца, самонастройка бота после деплоя, бэкапы D1 через GitHub Actions.

## Стек
Astro 7 (SSR) · Cloudflare Workers Free · D1 + Drizzle · Workers KV (фото) · React · Tailwind 4 · Manrope · grammY · Zod · Vitest.
Размер Worker ≈ 0,42 МБ gzip (лимит 3 МБ).

## Локально
```bash
npm ci
cp .dev.vars.example .dev.vars
npm run db:migrate:local && npm run db:seed:local && bash scripts/seed-photos.sh --local
npm run build && npx astro preview --port 8787 --host 127.0.0.1
# в другом терминале
npm test && npm run test:e2e
```
Откройте http://127.0.0.1:8787. Админ-панель работает только внутри Telegram (подпись initData).

## Деплой
`git push origin main` — Cloudflare Workers Builds собирает и выкладывает автоматически. Подробности — `docs/DEPLOY.md`.

## Проверки
- `npm test` — 28 юнит-тестов: подпись initData, скрытые поля, форматы, санитайзер Markdown, курсы валют, адреса фото.
- `npm run test:e2e` — 96 сквозных проверок на локальном Worker.
- `NODE_PATH=$(npm root -g) node tests/e2e/screens.mjs` — скриншоты ключевых экранов.
- CI (`.github/workflows/ci.yml`) прогоняет всё это на каждый push.
