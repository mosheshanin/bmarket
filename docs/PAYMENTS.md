# Оплата размещения объявлений

> **Сейчас (с 24.10.2026) онлайн-оплата выключена** (`ONLINE_PAYMENTS = "0"` в `wrangler.jsonc`).
> Продавец нажимает «Отправить заявку на размещение» → в группу менеджеров приходит заявка: лот, отрасль, город,
> цена бизнеса, Telegram продавца, состав и сумма к оплате (размещение + оценка + аудит) и ссылка в админку.
> Скрытые данные (телефон, название, адрес) в группу не уходят — они в карточке лота в админке.
> Менеджер согласует оплату с продавцом и нажимает «Отметить оплату вручную» → публикация сразу или после проверки
> (переключатель в админке «От продавцов»). Ниже — как работает и как включить PayPal, когда понадобится.

## PayPal (выключен)

### Как работает

1. Продавец заполняет объявление на `/sell` (кнопка «Продать свой бизнес» в боте, команда `/sell`, блок на главной).
   Черновик сохраняется на сервере автоматически.
2. «Отправить и перейти к оплате» → этап `awaiting_payment`. Править больше нельзя (можно вернуть в черновик до оплаты).
3. «Оплатить через PayPal» → сервер создаёт заказ (Orders API v2, валюта ILS, сумма из настроек) →
   страница PayPal открывается **во внешнем браузере** (`WebApp.openLink`).
4. После оплаты PayPal возвращает на `/pay/paypal/return?token=<заказ>` → сервер списывает деньги (capture),
   сверяет сумму и валюту, записывает платёж в `payments`.
5. Дальше автоматически:
   - «Публиковать сразу после оплаты» включено → объявление публикуется, подписчики получают рассылку,
     продавцу — сообщение от бота, менеджерам — сообщение в группу;
   - выключено → этап `in_review`, менеджерам сообщение со ссылкой в админку; публикует администратор.
6. Если продавец закрыл браузер, не вернувшись: вебхук PayPal (если настроен) или сверка по расписанию раз в минуту
   (заказы младше 3 дней) завершат оплату сами. Повторы безопасны: публикация происходит один раз.
7. После публикации — только «Запросить изменения» (раздел «Мои объявления»).

Без ключей PayPal всё остальное работает: объявление ждёт оплаты, менеджеры получают сообщение, администратор
нажимает «Отметить оплату вручную» в карточке лота (например, при оплате переводом или Bit).

### Подключение (делает владелец)

0. В `wrangler.jsonc` поставить `"ONLINE_PAYMENTS": "1"`.

1. Бизнес-аккаунт PayPal (Израиль) → https://developer.paypal.com → **Apps & Credentials**.
2. Сначала режим **Sandbox**: создать приложение, скопировать *Client ID* и *Secret*.
3. Cloudflare → Workers → `bmarket` → Settings → Variables and Secrets → добавить **секреты**
   `PAYPAL_CLIENT_ID` и `PAYPAL_CLIENT_SECRET`. В `wrangler.jsonc` оставить `PAYPAL_ENV: "sandbox"`.
4. Вебхук (рекомендуется): в приложении PayPal → Webhooks → Add →
   URL `https://bmarket.moshemadwords.workers.dev/api/paypal/webhook`, события
   `Checkout order approved`, `Payment capture completed / denied / refunded / reversed`.
   Полученный *Webhook ID* → `PAYPAL_WEBHOOK_ID` в `wrangler.jsonc` (не секрет) → push.
5. Проверить тестовым покупателем Sandbox (Developer Dashboard → Sandbox accounts).
6. Боевой режим: Live-ключи → те же секреты, `PAYPAL_ENV: "live"`, вебхук создать заново в Live → новый `PAYPAL_WEBHOOK_ID`.

Цена размещения и режим публикации меняются в админке: «Объявления» → «От продавцов».

## ⚠️ Правила Telegram

Telegram требует, чтобы **цифровые товары и услуги** внутри ботов и мини-приложений оплачивались
**Telegram Stars**; боты, принимавшие такие платежи иначе, блокировались. Платное размещение объявления —
скорее цифровая услуга. Оплата PayPal во внешнем браузере снижает, но не убирает риск блокировки @bismarketbot.
Варианты: (а) оставить PayPal и принять риск; (б) добавить оплату Stars внутри Telegram, PayPal — только на сайте;
(в) брать оплату вне приложения (менеджер выставляет счёт) и отмечать её вручную — уже работает.
Решение — за владельцем; при необходимости проконсультироваться с юристом.

## Код

- `src/server/paypal.ts` — токен, создание/получение/списание заказа, проверка подписи вебхука.
- `src/server/seller.ts` — черновики продавцов, отправка, оплата, автопубликация, запросы на изменение, сверка.
- `src/pages/api/seller/[...path].ts` — API продавца (initData Telegram, только свои объявления).
- `src/pages/api/paypal/webhook.ts`, `src/pages/pay/paypal/return.astro`, `cancel.astro`.
- `src/seller/SellerApp.tsx` — интерфейс «Мои объявления»; `src/admin/SellerOverview.tsx`, `SellerPanel.tsx` — админка.
- Тест: `tests/e2e/smoke.mjs` поднимает поддельный PayPal на `127.0.0.1:8799` (`PAYPAL_API_BASE` в `.dev.vars`).
