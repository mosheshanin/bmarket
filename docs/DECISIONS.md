# Решения и отступления от ТЗ

Фиксируем всё, что реализовано иначе, чем буквально написано в `docs/SPEC.md`, и почему.

| № | Тема | Как в ТЗ | Как сделано | Почему |
|---|---|---|---|---|
| 1 | Таблицы | 8 таблиц | 8 таблиц ТЗ + `audit_log`, `broadcasts`, `settings` | Журнал изменений (8.7), очередь рассылок порциями (7.3) и дата последнего оповещения о курсе нужно где-то хранить |
| 2 | Статус лота | `draft / published / hidden` | + служебный `deleted` | Удалённый черновик остаётся строкой: номер лота не переиспользуется, а фото стираются из R2 через 30 дней (12.4) |
| 3 | Фото | WebP 1600 + 600 | WebP; если браузер не умеет кодировать WebP (Safari/iOS) — JPEG | Safari не поддерживает WebP в `canvas.toBlob`. Сервер принимает оба формата и проверяет сигнатуру файла |
| 4 | Курс валют | «проверить адрес API» | Основной — SDMX `edge.boi.gov.il` (ряды `RER_USD_ILS`, `RER_EUR_ILS`), запасной — `boi.org.il/PublicApi/GetExchangeRates` | Оба адреса проверены 24.10.2026 |
| 5 | Заявки: антиспам | лимит по IP | В `leads` хранится хеш IP (`ip_hash`) с солью, сам IP не хранится | Нужен для лимита 5 заявок/час; стирается вместе с ПДн через 24 месяца |
| 6 | Рассылка | «не чаще 1 раза в 2 часа» | Плюс пауза 2 минуты перед первой отправкой | Лоты, опубликованные подряд, уходят одной подборкой, а не «первый отдельно, остальные через 2 часа» |
| 7 | Кеш страниц | 10 минут, сброс при изменениях | Ключ кеша включает ID версии Worker (`CF_VERSION_METADATA`) | Иначе после деплоя HTML из кеша ссылается на удалённые CSS/JS и сайт до 10 минут без стилей |
| 8 | Выгрузка CSV | «выгрузка в CSV» | Две кнопки: скачать (подписанная ссылка на 5 минут, `WebApp.downloadFile`) и «прислать в чат с ботом» | Внутри Telegram обычное скачивание работает не везде |
| 9 | Кнопка «Открыть в админке» в группе | открывает мини-приложение | URL-кнопка `t.me/<бот>/<app>?startapp=lead-57` | Кнопки `web_app` в группах Telegram запрещены |
| 10 | Предпросмотр лота | «как увидит посетитель» | Та же страница карточки по подписанной ссылке `?preview=…` (1 час), без кеша и с `noindex` | Предпросмотр 1:1 с реальной карточкой без дублирования вёрстки |
| 11 | Slug города | — | Slug города после создания не меняется (меняются только названия) | Не ломать проиндексированные адреса `/city/<slug>` |
| 12 | Окупаемость | цена / прибыль | Округление до целых месяцев; от 24 мес. дополнительно в годах | Читаемость |
| 13 | Хранилище фото | R2 | Workers KV (`PHOTOS_KV`); R2 подключается добавлением привязки `PHOTOS` без изменения кода | R2 требует привязки карты, владелец выбрал вариант без карты. Лимит KV Free — 1000 записей в день (≈500 фото в день) и 1 ГБ (≈2000 фото) |
| 14 | Резервные копии | закрытый бакет R2 | Артефакт GitHub Actions в приватном репозитории, хранение 56 дней | Нет R2 |
| 15 | Секрет вебхука | отдельный секрет | Если `TELEGRAM_WEBHOOK_SECRET` не задан — выводится из токена бота (HMAC) | В Cloudflare достаточно одного секрета `TELEGRAM_BOT_TOKEN` |
| 16 | Настройка бота | скрипт с компьютера | Worker сам настраивает вебхук, команды, кнопку меню и описание при первом запуске cron после каждого деплоя | Из среды разработки нет доступа к api.telegram.org; так надёжнее и после смены токена |
| 17 | Staging | отдельный Worker и тестовый бот | Не используется — сразу production | Решение владельца (тестового бота не будет). Проверки — автотесты в CI на локальном Worker |
| 18 | Шрифт | системный | Manrope (вариативный, кириллица), раздаётся вместе с приложением, кириллица — с preload | Решение владельца |
| 19 | Заставка при открытии | — | «Сторис» (5 сцен, ≈6,7 с) при каждом открытии мини-приложения; кнопка «Пропустить»; не в браузере, не в админке, не при «уменьшении движения»; при прямой ссылке на лот показывается уже на карточке; нижняя кнопка Telegram появляется после заставки | Решение владельца (вариант A из прототипов) |
| 20 | Демо-объявления | 3 тестовых лота | В production — 10 демо-лотов (1001–1010), по 3 реальных фото Unsplash на лот (ключи `unsplash:<id>:<ширина>`, картинки с CDN Unsplash в нужном размере 4:3); в скрытых заметках «ДЕМО» | Коннектор не умеет писать в KV, а из среды разработки нет доступа к фотостокам. Лицензия Unsplash разрешает бесплатное коммерческое использование без указания автора; авторы перечислены в `scripts/demo-lots.mjs`. Перед реальным запуском — снять с публикации |
| 21 | Группа менеджеров | ID из `MANAGERS_CHAT_ID` | ID может заменить бот: `/setgroup` в группе (только администратор), добавление бота в группу администратором, переход группы в супергруппу (`migrate_to_chat_id`). Замена хранится в `settings.managers_chat_id` и важнее переменной; последняя ошибка — в `settings.managers_last_error` и видна в админке («Заявки» → «Группа менеджеров») | Заявка №1 не дошла: Telegram отклонил отправку, а точной причины не было видно. Теперь причина показывается по-русски, а частые случаи исправляются без деплоя |
| 22 | Объявления от продавцов | нет в ТЗ (добавлено 24.10.2026) | Страница `/sell` (мини-приложение): пошаговая форма, автосохранение черновика на сервере через 1,5 с + копия в телефоне без сети. Хранится в `businesses` (`seller_tg_id`, `seller_stage`), поэтому публикация, кеш, рассылка и заявки работают как у лотов администратора. Черновики продавцов получают номер лота сразу (в нумерации возможны пропуски) | Решение владельца. Один код карточки и публикации — меньше ошибок |
| 23 | Оплата размещения | нет в ТЗ | PayPal Orders API v2 без JS SDK: сервер создаёт заказ, оплата — на странице PayPal во **внешнем браузере**, списание при возврате на `/pay/paypal/return`, подстраховка — вебхук `/api/paypal/webhook` (подпись проверяется через API PayPal) и сверка раз в минуту. Цена (по умолчанию ₪ 199) и режим «сразу публиковать / после проверки» — в админке, вкладка «От продавцов». Без ключей PayPal — объявление ждёт оплаты, менеджеры получают сообщение, оплата отмечается вручную | Окна PayPal в WebView Telegram работают ненадёжно. ⚠️ Риск: правила Telegram требуют Telegram Stars для цифровых товаров/услуг внутри ботов и мини-приложений — см. `docs/PAYMENTS.md` |
| 24 | Правки после оплаты | — | После отправки продавец не редактирует объявление (API отвечает 409); «Запросить изменения» → таблица `edit_requests`, сообщение в группу менеджеров, в админке — блок «Объявление от продавца» с кнопками «Изменения внесены» / «Отклонить» (продавцу приходит ответ в Telegram). До публикации администратор может «Вернуть на доработку» — повторная оплата не нужна | Решение владельца |
| 25 | Кнопка «Админ-панель» | — | Внизу справа (с учётом safe-area), не на странице продавца | Решение владельца: сверху перекрывала заголовок |
| 26 | Опрос при первом запуске | нет в ТЗ (добавлено 24.10.2026) | Только мини-приложение, только главная, после заставки; 5 вопросов (купить: сфера, город, бюджет, пожелания; продать: сфера, город, сроки, пожелания; «просто смотрю» — сразу каталог). Ответы — таблица `visitor_profiles`, копия в телефоне. **Выключен по умолчанию**: включается в админке «Статистика» → «Опрос при первом запуске»; предпросмотр — `/?survey=1`. Механики без игровых элементов: честный прогресс и время, живой счётчик «Подходит сейчас: N из M», количество предложений на вариантах ответа, реальный спрос для продавцов (покупатели из опроса ≥ 3 или просмотры сферы ≥ 10 за 30 дней, иначе нейтральный текст), итог — подборка, уведомления только о подходящих, связь с менеджером (телефон — системным окном Telegram) | Решение владельца. Модуль грузится отдельно и только в Telegram — сайт для поисковиков не тяжелеет |
| 27 | Рассылка о новых лотах | всем подписчикам | Кто в опросе включил «только подходящие», получает подборку только из лотов под свои ответы (или ничего) | Меньше лишних сообщений — меньше отписок |
| 28 | Оформление карточки бизнеса | — | Блоки разного оттенка по смыслу: цена — синий, оборот — синий, прибыль и «что входит» — зелёный, окупаемость — фиолетовый, аренда и причина продажи — янтарный, характеристики — бирюзовый, описание — нейтральный. Цвет подмешивается к фону (`color-mix`), классы `.tinted .tone-*` в `global.css` | Решение владельца: проще воспринимать |
